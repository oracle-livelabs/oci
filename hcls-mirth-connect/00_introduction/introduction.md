# Introduction

## About this Workshop

This workshop takes you step by step through the process of creating the required Oracle Cloud Infrastructure (OCI) resources, and deploying an open-source healthcare integration engine, Mirth Connect, on OCI Kubernetes Engine (OKE).

Estimated Workshop Time: 1 hour and 10 minutes

### What is Healthcare Interoperability
Healthcare interoperability is the ability of different healthcare systems and applications to securely exchange and use health information. It enables healthcare providers to access patient information across different systems and organizations. Mirth Connect is a healthcare integration engine that can facilitate the exchange of healthcare data between disparate systems.

### Objectives

In this workshop, you will:
- Provision the OCI resources required to run the open-source Mirth Connect.
- Deploy Mirth Connect on OKE.

### Prerequisites

This lab assumes you have:
* Access to an OCI tenancy
* Sufficient privileges to create OCI resources in an OCI Compartment
