# Set up API Authentication for OCI

## Introduction

This lab describes how to set up API authentication so that you can authenticate to OCI from a local environment, such as your computer.

Estimated Lab Time: 20 minutes

### Objectives

In this lab, you will:

* Create API keys in the OCI Console.
* Set up an OCI configuration file for API authentication from your local environment.
* Install OCI CLI in your local environment.

## Task 1: Set up API Authentication for OCI

1. Follow the [OCI documentation](https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/setup-oci-api-auth.htm) to set up API authentication for OCI.

You may now **proceed to the next lab**.
