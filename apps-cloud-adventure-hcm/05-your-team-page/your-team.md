In this activity, you will learn how to create new journey experiences. 

Estimated Time: 7 minutes

## Objectives

In this activity, you will::
* Set up a Journey. 

## Task 1: Journeys Setup

Easily create and maintain your journey experiences in Journeys Setup.

1. From the Home Page, click the **My Client Groups** tab, and then the **Journeys Setup** tile 

    ![Journeys Setup Tile](images\JourneysSetupTile.png)

The Journeys Setup screen centralizes configuration and management of journey templates, guided tasks, task libraries, and task groups used to deliver structured user experiences. It also enables administrators to manage integrations and system configurations to control how journeys are assigned, executed, and monitored.

2. Click the **Journey Templates** area.

    ![Journeys Templates Access](images\JourneysTemplatesButton.png)

The Journey Templates area is where administrators create, update, and manage reusable journey frameworks that define the structure, tasks, and flow of user experiences.

3. Click **‘Tasks’** under **‘Actions’** for **‘Welcome to the Team!**

    ![Welcome to the Team Tasks](images\WelcomeTasks.png)

A preview panel displays all tasks in the journey, including both required and optional tasks, along with their task type and the assigned performer or owner.

4. Click **‘X’** in top right corner to close this view.

    ![Close Welcome Tasks](images\CloseWelcomeTasks.png)

5. Click **‘Welcome to the Team!’** to view the detailed configuration and tasks for a sample journey.

    ![Welcome to the Team Template](images\WelcomeTemplate.png)

6.	Scroll down and preview existing Tasks.

7. Under **‘+ Add’,** administrators can create a new task, add an existing task from the task library, or add a task group, which is a predefined collection of related tasks

    ![Add Task](images\AddTask.png)

8. In **‘Suggest Tasks’,** administrators can leverage generative AI to produce a suggested task to add to the existing journey. Click **‘Cancel’** in bottom left corner to close this view.

    ![Cancel New Task](images\CancelNewTask.png)

9. Under **‘Actions’,** click the **pencil icon** for **‘Update Your Address’** to edit an existing task.

    ![Update Address Action](images\UpdateAddressAction.png)

10. Under **‘Generate’,** administrators can use generative AI to create task instructions and control their tone.

    ![Generate Task Instructions](images\GenerateAddressInstructions.png)

11. Scroll down. 

12. Under **“Performer,”** administrators define who the task is assigned to—such as the worker assigned the journey, a specific individual, an area of responsibility, or the worker’s line manager. The same options apply for defining the task owner.

    ![Performer Drop Down](images\PerformerDropDown.png)

13. Under **‘Task Type’,** administrators can specify the desired type of task (e.g., application task, electronic signature, external URL) and set the task’s due date or duration.

    ![Task Type Drop Down](images\TaskTypeDropDown.png)

14. Scroll up.

15. Under **‘Advanced’,** administrators can assign eligibility at the task level or select a preceding task. Click **‘Cancel’** in the bottom right to close this view.

    ![Advanced Tab](images\AdvancedTab.png)

16. Click **'<' (back arrow)** to return to **Journey Templates** area.

    ![Back to Journey Templates](images\BackToJourneysTemplates.png)

17. Click **‘Create’** to start a new journey from scratch, or click **‘Use Existing’** to use an existing journey as a blueprint.

    ![Create Journey Template](images\CreateJourneyTemplate.png)

18. Click **‘AI Assist’** to leverage generative AI to suggest tasks for your journey. Select a category and type in a prompt of your choice (e.g. development journey for aspiring senior leaders), then click **‘AI Assist’.**

    ![Generate Journey Tasks](images\JourneyTasksAI.png)

19. Scroll down.

20. Under **‘Task Suggestions’,** administrators can choose from the suggested tasks as a starting point for their new journey. Click **‘Create Draft’** to proceed—or **‘Cancel’** to exit this view. 

    ![Task Suggestions](images\TaskSuggestions.png)
